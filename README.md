# 🎱 ビリヤード ストローク解析

ビリヤードのストローク動画をアップロード（またはスマホのカメラで撮影）すると、ブラウザ内で姿勢推定を行い、フォームの修正ポイントを自動でスコアリングするWebアプリです。動画は外部サーバーに送信されず、すべて端末上（ブラウザ）で解析されます。

## 主な機能

- 動画アップロード / スマホカメラでの直接撮影に対応
- [MediaPipe Pose Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker) によるブラウザ内姿勢推定
- スライダーによるストローク区間のトリミング
- 4つの観点（肘の安定性・手首軌道の直線性・頭の安定性・テンポの滑らかさ）での自動採点と、日本語での具体的な修正アドバイス
- 手首の軌道を可視化するミニグラフ

## 開発

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```

## デプロイ（Vercel）

Vite製プロジェクトのため、Vercelにインポートするだけでゼロコンフィグでデプロイできます。

```bash
npx vercel
```
